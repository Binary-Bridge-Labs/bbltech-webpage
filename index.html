面部重现

大型语言模型

我们主要使用 Chat-GPT API 来支持我们的应用，例如 Ask AI 和 Type AI。此外，我们还训练模型以使其适应特定场合，例如担任助教（Nerd AI）或模仿心爱的名人（Charsis AI）
